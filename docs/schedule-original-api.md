# 확정된 근무 시간표와 주당 근무 시간 API

## 개념

- **확정된 근무 시간표**: 근무 전에 합의한 요일 기준 표 **1개**. 거의 바뀌지 않으며 주와 무관하다. API 경로는 기존 `/schedule/original`을 유지한다.
- **주간 근무 시간표**: 실제 `shifts`. 매주 확정표에서 복사해 만들고, 그 주의 변경은 이쪽만 바꾼다. 확정표와 다른 근무는 빨간색, 빠진 확정 근무는 빨간 점선으로 표시한다. 주간표 변경은 확정표에 반영하지 않는다.
- **주당 근무 시간**: 확정표로 계산한다. 근무자별 조정값은 주와 무관하게 하나만 둔다.

## 화면

- 위: 주간 근무 시간표. 상단 `확정표에서 가져오기`로 대상 주에 확정표를 붙여넣는다.
- 아래: 확정된 근무 시간표와 그 옆 주당 근무 시간. 확정표는 어느 주를 보든 같은 내용이며, 보는 주의 날짜에 맞춰 표시한다.
- 확정표는 09:00~22:00의 1시간 행, 월~금 요일별 4개 근무자 칸(첫 칸 데스크, 나머지 대기)으로 표시한다. 30분 근무는 칸의 위/아래 절반을 채운다.
- 관리자는 확정표에서 근무를 추가하거나 이름을 눌러 요일·근무자·시간을 수정·삭제한다. 확정표가 비어 있으면 `현재 주간표로 최초 확정`으로 지금 보는 주간표를 요일 기준 확정표로 저장할 수 있다.
- 주당 시간에서 이름을 누르면 총 시간·데스크 시간·오픈·마감을 조정한다. 조정값은 모든 주에 공통이며 `확정표 기준으로 되돌리기`로 삭제한다.
- 총 시간은 확정 근무 분 합계, 데스크 시간은 desk 역할 분 합계, 오픈은 09:00에 시작하는 요일 수, 마감은 그 요일의 최종 종료 시각(최솟값 21:00)에 끝나는 요일 수다.

## API (`/library-dashboard/api` 기준)

조회는 로그인, 저장·삭제는 관리자 권한과 CSRF가 필요하다.

### GET `/schedule/original`

```json
{
  "saved": true,
  "staff": [{ "id": 1, "name": "홍길동", "phone": "", "active": 1 }],
  "shifts": [{ "id": 101, "staff_id": 1, "weekday": 1, "start": 540, "end": 600, "role": "desk" }]
}
```

`weekday`는 1(월)~5(금). 확정 근무가 없으면 `saved: false`, `shifts: []`.

### PUT `/schedule/original`

`{ "shifts": [{ "staff_id": 1, "weekday": 1, "start": 540, "end": 600, "role": "desk" }] }` — 확정표 전체를 교체한다. 요일·09:00~22:00·30분 단위·같은 사람 같은 요일 겹침을 검증한다. 퇴직한 근무자의 기존 근무도 저장할 수 있다.

### POST `/schedule/original/copy`

요청 `{ "target": "2026-11-02", "overwrite": false }`. target은 해당 주 월요일로 정규화한다.

- 대상 주에 근무가 있고 `overwrite`가 아니면 아무것도 바꾸지 않고 `{ "ok": false, "existing": 12 }`를 반환한다. 화면은 덮어쓸지 묻고 `overwrite: true`로 다시 요청한다.
- 덮어쓰면 대상 주 근무를 지운다.
- 퇴직한 근무자의 근무는 빼고 붙여넣는다. 응답 `{ "ok": true, "count": 62, "skipped": 2 }`.
- 확정표가 비어 있으면 409.

### GET `/schedule/hours`, PUT·DELETE `/schedule/hours/{staff_id}`

GET은 `{ "overrides": [{ "staff_id": 1, "total_minutes": 600, "desk_minutes": 300, "opens": 1, "closes": 1 }] }`로 조정한 근무자만 반환한다. PUT 본문은 `{ total_minutes, desk_minutes, opens, closes }`(0~3900분 30분 단위, 데스크 ≤ 총 시간, 오픈·마감 0~5회). DELETE는 조정값을 지워 확정표 계산값으로 되돌린다.
